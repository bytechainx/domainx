# domainx 语义标准

## 职责

`domainx` 定义多个交易子系统共享的纯领域值对象与显式校验函数。

## 范围

- 共享订单、持仓、成交、执行回报、组合及枚举类型。
- `InstrumentKey` 是标的身份值对象；数值依赖由 `decimalx` 提供。
- `validate` 函数执行纯数据约束检查，调用方决定何时校验。

## 约束

- 不执行下单、风控、PnL 计算、网络请求或持久化。
- 构造和 serde 反序列化不自动保证所有跨字段业务约束；调用方按需显式调用校验函数。
- 公开字段、枚举变体及序列化 shape 均属于兼容契约，变更须同步本文件和测试。
